01 · Problem

What need does it solve?

Some information is worth following every day or every week: world news, new films in theaters, new tools, a subject I am studying. Following each one by hand takes time, and it is easy to fall behind.

I wanted each of these to arrive on its own, already researched and written, in a format that is quick to read.

02 · Solution

How it works

Each briefing is a scheduled Claude routine with its own instructions. On every run it researches what is new, writes the issue and delivers it, with no manual step:

  • World Brief: every evening, the day's news by email and a world section on a public site with an archive
  • Wednesday Cinema Bulletin: every week, the notable films in theaters with reviews, showtimes and a reason to see each one
  • Daily Claude Idea: every day, one lesser-known Claude feature and a project that puts it to work, published to a web page
  • A Year of Film Theory: a short lesson every day, readings, a film each week and weekly tests

03 · Architecture

How the system fits together

All four follow the same pattern. A schedule starts the routine, which reads its instructions, researches the web and writes the issue. The issue then goes out by email, to a web page, or both. Web issues are saved as files in a GitHub repository and served by GitHub Pages, so every past issue stays available.

05 · Challenges

Hard parts and how they were solved

  1. Fresh every time

    Each routine checks what earlier issues already covered, so stories, films and ideas are not repeated.

  2. Reliable with nobody watching

    Issues are checked against a fixed format before they are sent or published, and failed runs can simply run again.

  3. Short enough to read

    Each format has strict limits: a few stories, a few films, one idea, one lesson, so an issue takes minutes to read.

06 · Results

What came out of it

  • Four briefings running on their own since autumn 2026.
  • An archive of every web issue, available on any device.
  • Time saved every day on following news, films, tools and study.
