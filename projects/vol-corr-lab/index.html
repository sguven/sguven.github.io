Volatility & Correlation Laboratory

A free online course and Python library on volatility and correlation risk: estimating volatility, the implied volatility surface, vega risk, variance swaps, correlation stress and how FRTB capitalises both.

01 · Problem

What need does it solve?

Volatility and correlation are second-order risks: they rarely show up in a simple position report, yet they decide how an options book or a structured-products book behaves when markets turn. Both tend to rise exactly when it hurts most.

The topics are spread across estimation methods, surface models, trading products and capital rules. The aim was one place where each step is explained, implemented and checked.

02 · Solution

How it works

Seven chapters are read in order, each backed by a module of the vclab package:

  • What volatility and correlation risk are, and the market episodes from 1987 to 2020 behind them
  • Measuring volatility with rolling windows, EWMA and GARCH(1,1), and the volatility cone
  • The implied volatility surface: SVI, arbitrage checks, local and stochastic volatility
  • Vega risk, variance and volatility swaps, and a VIX-style index
  • Correlation estimation, stress and repair, implied correlation and correlation products, then the FRTB treatment of both risks

03 · Architecture

How the system fits together

An illustrative volatility surface, a small stock universe and simulated return histories feed the vclab package. It estimates volatility, values a delta-hedged options book off the surface, measures and stresses vega and correlation, and turns the results into FRTB capital figures. On each push, GitHub Actions runs the tests and publishes the course to GitHub Pages next to the other two labs.

05 · Challenges

Hard parts and how they were solved

  1. A surface without arbitrage

    Each expiry is fitted with SVI and checked for butterfly and calendar arbitrage, so prices read off the surface stay consistent.

  2. Vega that adds up

    Bucketed vega is built so the buckets sum to the parallel vega; the tests confirm it, so a risk report can be reconciled.

  3. Stress that stays valid

    A stressed correlation matrix can stop being a valid matrix. The library repairs it to the nearest valid one instead of using a broken input.

  4. Being clear about limits

    Data are illustrative and simplified, and each chapter says so, so the results are read in the right context.

06 · Results

What came out of it

  • One connected path from estimating volatility to the capital held against an options book, readable on any device.
  • A tested Python library for volatility and correlation risk that can be extended.
  • Shows, for example, how an options book that is long vega can still lose when short-dated volatility rises more than long-dated, and how correlation jumps in a crisis.
