WorkoutLog Pro

A mobile web app for logging gym sessions between sets: it shows last time's numbers, suggests when to add weight, keeps a rest timer and turns the history into a weekly muscle map and a Sunday coaching email.

01 · Problem

What need does it solve?

Most workout apps are built around browsing: programs, videos, feeds. In the gym the need is smaller. I want to see what I lifted last time, enter the next set with one hand, and not lose my place while I rest.

I also wanted the history to say something: whether each muscle is getting enough work in a week, and when a lift is ready to go heavier, without keeping a spreadsheet.

02 · Solution

How it works

The app opens on the next session in the program. From there it:

  • Shows last time's sets for each exercise, so the next entry starts from known numbers
  • Suggests a heavier weight when every set reached the top of the rep range
  • Starts a rest timer when a set is ticked off
  • Shows weekly sets per muscle on a muscle map, with personal records and a chart for each exercise
  • Keeps a library of 40+ exercises with form cues and the muscles they work, and lets any exercise in the program be swapped
  • Sends a coaching email every Sunday from a scheduled AI task, covering how the week went and what to adjust

05 · Challenges

Hard parts and how they were solved

  1. Logging with one hand, mid-workout

    Between sets there is little attention to spare. Last time's numbers are shown for each exercise, a set is ticked rather than typed out, and ticking it starts the rest timer, so the screen needs few taps.

  2. Knowing when to go heavier

    Progress usually stalls because nobody checks the numbers. The app applies a simple rule: when every set reaches the top of the rep range, it suggests a heavier weight for the next session.

  3. A program that fits the person

    A generic plan ignores the schedule and the equipment available. The program is written by AI from a goal, the days available and the equipment, and any exercise can be swapped from the library without breaking the rest of the plan.

  4. A public demo without a real history

    The live demo cannot use private workouts. It opens with four weeks of sample history generated relative to today, so the progress screens always look current, and a double tap on Reset restores it.

06 · Results

What came out of it

  • A session can be logged between sets with a few taps, starting from the previous numbers.
  • The muscle map shows at a glance which muscles are getting enough weekly sets and which are not.
  • The Sunday email turns the week's workouts into feedback on how it went and what to change.
