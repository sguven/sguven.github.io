# sguven.github.io

**Live:** https://sguven.github.io

Project portfolio of Serhat Guven: twelve projects designed and built with AI across six fields — finance, automation, everyday apps, learning, content and personal.

| Path | What it is |
|---|---|
| `index.html` | The portfolio page (single file; images open in an in-page viewer; visitor progress is kept in the browser's local storage) |
| `img/` | Screenshots of real outputs; finance app screenshots use illustrative figures |
| `archive/v1-newspaper/` | Previous (newspaper-style) version of the portfolio, kept for reference; also saved as git tag `v1-newspaper` and branch `archive/v1-newspaper` |
| `daily-claude/` | [Daily Claude Idea](https://sguven.github.io/daily-claude/): one Claude feature and one project a day. A scheduled Claude task adds each entry to `entries.json` |

Static site served by GitHub Pages from `main`; no build step.
